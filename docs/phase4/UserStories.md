User stories for this phase:

“As a user, I want to upload documents in a message so that other people can access”
“As a user, I want to upload links in a message so that other people can access”
“As a user, I want to reply to a message containing a document so that I can give feedback”
“As a user, I want to reply to a message containing links so that I can give feedback”
“As an admin, I want to remove messages so that I can filter out harmful messages”
“As an admin, I want to remove documents so that I can filter out harmful documents”
