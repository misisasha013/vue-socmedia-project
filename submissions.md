Team submission/grading record

This file is used to track the grading status of your team throughout the semester and provide convenient access to the associated demo videos and git commits.

You will update this file throughout the semester and keep it version controlled in your team repo's `main` branch.

For each sprint of each phase you should include the...
* role, one of "backend", "admin", "webfe", "pm"
* uid, like `sml3` in `sml3@lehigh.edu`
* name, like `Stephen Lee-Urban`
* demo status of each team member, one of "panopto", "status unknown", "graded in person", 
    * if panopto, provide a link to the panopto video submission as a sub-bullet
    * there should be a direct link to the relevant branch (and possibly commit) on bitbucket

For example, see below.
